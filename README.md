# Design Patterns em Java

Este projeto tem como objetivo implementar e estudar os padrões de projeto (Design Patterns) apresentados no livro **"Mergulho nos Padrões de Projeto"**.

## Sobre o Projeto

As implementações deste repositório foram desenvolvidas com base nos pseudocódigos e exemplos conceituais apresentados no livro, adaptando-os para a linguagem Java com o objetivo de facilitar o aprendizado, a experimentação e a compreensão dos padrões de projeto.

O foco deste projeto é educacional, servindo como material de estudo e referência para desenvolvedores que desejam aprofundar seus conhecimentos em arquitetura de software e boas práticas de desenvolvimento orientado a objetos.

## Objetivos

- Estudar os padrões de projeto mais utilizados no desenvolvimento de software.
- Implementar exemplos práticos em Java.
- Compreender os problemas que cada padrão busca resolver.
- Analisar vantagens, desvantagens e cenários de aplicação.
- Criar uma base de consulta para futuras referências.

## Estrutura

Os exemplos estão organizados por categorias de padrões:

### Padrões Criacionais
- Singleton
- Factory Method
- Abstract Factory
- Builder
- Prototype

### Padrões Estruturais
- Adapter
- Bridge
- Composite
- Decorator
- Facade
- Flyweight
- Proxy

### Padrões Comportamentais
- Chain of Responsibility
- Command
- Iterator
- Mediator
- Memento
- Observer
- State
- Strategy
- Template Method
- Visitor
